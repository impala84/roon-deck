Why I built RoonDeck

A touchscreen should do more than show what is playing.

There are already excellent ways to turn a Raspberry Pi into a Roon audio endpoint, including RoPieee, with an optional Now Playing display. What I could not find was a dedicated touchscreen interface for browsing my Roon library.

I wanted a screen beside each listening zone for choosing an album, changing the queue or making a quick adjustment—without reaching for a phone or opening a computer. So I built RoonDeck.

Please note

Experimental Roon integration

Some of RoonDeck’s library and discovery features use a reverse-engineered internal Roon interface. It is not a stable public API, so a future Roon update may break those features without warning. I use RoonDeck every day and intend to keep it working and updated, but compatibility cannot be guaranteed.

Get started

Download the image to get started.

Five straightforward steps take RoonDeck from an image file to a dedicated music touchscreen.

Stable release v1.1.6View the release notes for v1.1.6. For a new installation, flash the installation image below, then update to v1.1.6 in Settings → Software.
Download v1.1.6
  1. 1

    Download the image

    Get the RoonDeck ARM64 installation image. The same image supports Raspberry Pi 3, 4 and 5. After setup, select the Stable channel in Settings → Software and update to stable v1.1.6.

  2. 2

    Flash your card

    Use Raspberry Pi Imager or balenaEtcher to write the downloaded .img.gz file to a 16GB or larger microSD card.

  3. 3

    Connect the hardware

    Check the recommended hardware, insert the card, connect the touchscreen and network, then apply power. Leave the first boot running while RoonDeck prepares the card.

  4. 4

    Complete setup

    Choose the display and orientation, connect Wi-Fi if needed, set the timezone, then choose optional Roon Bridge, AirPlay and Netdata services.

  5. 5

    Connect Roon

    Enable RoonDeck in Roon Settings → Extensions, choose the zone you want to control and start browsing.

Troubleshooting and advanced options

No controller in Roon?

Confirm the Pi and Roon Server are on the same local network, then check Roon Settings → Extensions.

Display or touch rotated?

Select the exact display model and orientation in RoonDeck Settings, apply the change and reboot.

Want a RAAT endpoint?

Enable Roon Bridge in RoonDeck Settings, then enable the Pi output separately in Roon Settings → Audio.

Need help?

Capture the display from web Settings and include it when opening a GitHub issue.
