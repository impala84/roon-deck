    WireGuard VPN

    Turning this off disconnects the VPN. Your saved profile is kept.

    Disconnected

    Routing follows the profile's AllowedIPs. IPv6 needs an IPv6 tunnel address and ::/0. Roon cannot be found automatically through a VPN. Enter your home Roon Core's address, then save it; the Pi connects to it directly. It is also used for the connection check. Private keys are stored in a protected system profile and are never returned to this page. Disconnect before replacing the profile.
    Confirm from this page or the touchscreen within 90 seconds. Otherwise the tunnel disconnects automatically. Disconnect also turns off automatic connection on boot.

    Roon Discovery · experimental

    Relays discovery only, using the Pi’s VPN address. Existing VPN, Bridge and audio settings are preserved. The Server route must already use WireGuard.

    Disabled

    Relayed packets do not confirm discovery. Verify the Pi appears in Roon → Settings → Audio, then test playback and reconnection.
